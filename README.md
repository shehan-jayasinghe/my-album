# My Album

A React application for experimenting with album-style UI and frontend development.

## Development

Install dependencies and start the development server:

```bash
npm install
npm start
```

Open `http://localhost:3000/` in a browser.

## Common Commands

```bash
npm start
npm test
npm run build
```

## Purpose

The project is useful for practicing React component composition, rendering collections of content, UI state, and responsive frontend behavior.

## Production

Run `npm run build` to create an optimized production build.

## Notes

Use the package versions already defined by the repository when installing and developing the application.
